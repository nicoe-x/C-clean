# Clearspace · AI 缓存管家

Windows 缓存清理与 C 盘空间分析工具。

[下载 Windows 版](https://github.com/nicoe-x/C-clean/releases/latest) · 下载 `Clearspace-5.exe` 后双击运行，无需安装 Python。

## 功能

- **Agent 扫描**：识别 Codex、Claude、WorkBuddy、豆包、ZCode、OpenClaw、Hermes 等工具，区分缓存和需保留的应用数据。[支持列表](SUPPORTED_APPS.md)
- **C 盘分析**：查看目录占用、大文件和文件类型，在「清理」页勾选支持清理的缓存。
- **一键选择**：点击「全选推荐项」，快速勾选建议清理的目录。
- **预览确认**：清理前核对文件清单，支持导出。
- **搜索与筛选**：按应用、路径和建议查找，支持收藏目录和导出报告。
- **主题切换**：浅色、深色或跟随 Windows 系统。
- **更多工具**：「支持列表」可搜索应用，也可添加自定义目录做只读分析。

## 使用

1. 打开程序，默认进入「Agent 缓存」；需要分析整个 C 盘时切换到「C 盘分析」。
2. 点击「扫描」，等待结果。
3. 查看清理建议，点击「全选推荐项」或手动勾选。C 盘模式请进入「清理」页。
4. 退出相关应用，点击「预览清理」，核对文件清单后确认删除。
5. 清理完成后重新扫描，查看空间变化。

默认清理 7 天前的缓存，可调整时间范围。会话、配置、技能、模型和运行时仅统计占用；未知目录不直接清理。文件删除后不进入回收站，请先核对预览清单。
