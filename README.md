# Clearspace · AI 缓存管家

Windows 本地窗口工具，使用 Python 标准库。扫描当前用户在 **C 盘** 的常见 AI 应用缓存，查看占用并按目录勾选清理。无联网、无管理员权限要求。

## 启动

从 [Releases](https://github.com/nicoe-x/C-clean/releases/latest) 下载 `Clearspace-5.exe`，双击运行。这是免安装单文件程序，无需安装 Python。

推荐双击 `dist/Clearspace-5.exe`（旧名称 `AI-Cache-Cleaner.exe` 也同步更新），无需安装 Python，也无需管理员权限。可以单独复制这个 exe 到其他文件夹或 Windows x64 电脑运行；首次启动需要几秒钟解包运行环境。

每次启动默认进入 **Agent 缓存清理**。顶部可以切换到 **C 盘全局分析**，两个模式各自保留当前结果；扫描或清理过程中需先停止或等待完成再切换。

源码运行需要 Python（含 Tkinter）。首次运行先按下方构建步骤生成图标资源，再双击 `启动工具.bat`。

1. 点击「开始扫描」。默认只把 7 天前最后修改的文件列入可清理范围。
2. 查看目录列表和清理建议。点击「全选推荐项」或单击第一列勾选；日志需单独勾选。双击一行或点击「详情」查看建议原因和影响；完整路径直接显示在表格中。
3. 退出准备清理的应用，点击「预览清理」，核对完整清理清单后确认执行。
4. 清理结束后重新扫描。扫描和清理报告自动保存到工具旁的 `reports` 文件夹；若该位置不可写，则保存到 `%LOCALAPPDATA%/AI-Cache-Cleaner/reports`。

选择 0 天表示包含扫描时已有的全部缓存文件。更改天数、取消扫描或完成清理后，需要重新扫描才能清理。未发现目录通常表示未安装该软件或使用了自定义路径。

## 清理建议与交互

| 建议 | 判断规则 | 自动选择 |
| --- | --- | --- |
| 推荐清理 | 无扫描异常、非日志、时间范围至少 7 天，且可释放不少于 10 MB 的白名单缓存 | 是，点击「全选推荐项」后勾选 |
| 按需清理 | 日志、较新的缓存，或可释放不足 10 MB | 否 |
| 建议保留 | 模型数据，只统计占用 | 不允许删除 |
| 无需清理 | 没有符合时间范围的文件或目录为空 | 不允许选择 |
| 先检查 | 有可清理文件，但扫描中遇到无法读取或涉及链接的条目 | 否 |

建议是基于本地规则的优先级提示，不会检测应用是否正在运行，也不能保证文件不再被使用。每个目录的详情都会说明原因和清理后的影响。模型优先标为保留，没有符合范围文件的目录标为无需清理，其余有扫描异常的目录优先标为先检查。

界面提供总占用、推荐清理和本次选择三块概览；支持应用/路径搜索、建议分类筛选、点击表头排序，以及空格切换勾选。F5 重新扫描，搜索框内 Esc 清空搜索。筛选保留已选项；「全选推荐项」会替换为全部推荐目录，包括当前筛选之外的推荐目录，最终确认清单会列出所有选择。更改时间范围会使旧扫描失效。

## C 盘全局分析模式

此模式从 `C:\` 扫描当前权限可访问的目录和文件元数据。分析不读取文件内容、不提权、不结束进程；新增独立的「清理建议 · 可勾选」页，只对白名单缓存开放清理。

- **目录分布**：显示每层目录的逻辑大小、占当前目录的比例、文件数、跳过项和保留 / 检查建议。双击逐层查看，点击「上一级」返回。直属文件单独合计，不与子目录重复统计。
- **大文件 Top 200**：保留全盘扫描中最大的 200 个文件，显示大小、修改时间和保留 / 检查建议；双击仅在资源管理器中定位，不执行文件。
- **文件类型**：按扩展名汇总逻辑大小和文件数。
- **跳过项**：记录不可读路径、链接 / 重解析点、目录别名及重复硬链接。界面和报告保留最多 500 条详情样本，同时保留全部原因计数。
- **停止与导出**：扫描可随时请求停止，已统计数据会汇总并标记为部分结果；尚未访问的目录显示「未扫描」。导出支持 HTML 和 CSV，自动 JSON 报告保存在 reports 中。CSV 目录大小含子目录，不可逐行相加；HTML 展示根目录分布、大文件、类型和跳过样本。
- **清理建议**：全盘扫描直接统计空间，不再先等待缓存检查。第一次进入清理建议页会按需独立检查已知缓存；也可点击「刷新清理建议」，无需重扫整个 C 盘。初始不勾选任何项，日志需手选。目录分布和大文件列表不会整项删除，只有此页通过检查的旧缓存可勾选。
- **预览确认**：点击「预览清理」显示完整文件列表（每页 200 个，可前后翻页、Ctrl+C 复制路径、导出全部清单），可以返回调整；取消不删除文件。确认后只处理预览中的固定文件快照，绝不补入扫描后新增的文件。
- **清理保护**：最短 7 天，可选 7 / 30 / 90 天。白名单限于当前用户的已知 Agent 缓存、手选日志、Chrome/Edge 默认及 Profile 数字配置的渲染缓存，以及 pip/npm 下载缓存。不清理系统目录、Program Files、ProgramData、回收站、任意 TEMP、模型、插件运行时、下载和个人资料目录。即使在缓存中，文档、媒体、数据库、凭据、配置、源代码、可执行程序和模型常见后缀也排除；仅允许明确的缓存后缀（含哈希无后缀文件、cache/dat/body/vsix/whl/log 等），来源不明的其他文件类型也排除；隐藏 / 系统 / 只读文件、硬链接和重解析点跳过。
- **执行与记录**：清理前先保存已确认文件清单（disk-cleanup-plan），随后生成逐文件删除 / 跳过结果（disk-cleanup）。写不出确认清单时不开始删除。文件将直接删除，不进入回收站。全盘统计和另一模式的旧清理勾选会失效，需重新扫描；可打开 Windows 存储设置管理系统可回收空间。

全盘扫描可能需要数分钟，取决于文件数和磁盘速度；无预先文件总数，扫描中显示实时文件数和逻辑大小，不显示虚构完成百分比。重解析点（含部分云文件占位符）不跟随。目录虚拟化别名跳过，硬链接文件只按首次遇到的路径计入一次，因而某些目录看起来比资源管理器小。逻辑文件大小与磁盘实际已用空间并不相等，也不代表可安全释放的空间；不可读路径、文件系统元数据、压缩和稀疏分配等都会影响差异。完成表示走完可访问范围，不表示读取了所有受保护内容。

## 图标与实用功能

- 自定义磁盘图标：exe 文件、窗口、任务栏和顶部品牌区域使用同一套蓝色磁盘图标，已内嵌到单文件程序中。
- 磁盘余量：标题区域显示 C 盘剩余空间、总容量及已用百分比，扫描和清理结束后更新。
- 按应用处理：应用下拉框过滤目录；「选择此应用推荐项」追加选择该应用的全部推荐目录，保留其他应用的选择。Ctrl+A 只追加选择当前可见的推荐目录，不会自动选日志。
- 收藏目录：在详情中收藏，或通过右键菜单操作；选择「收藏目录」分类即可快速查看。收藏只改变显示和偏好，不会扩大扫描或清理白名单。
- 右键菜单：快速打开目录、复制路径、收藏及选择当前可见推荐项；Ctrl+F 聚焦搜索框。
- 导出报告：可选择 HTML 网页（可直接打开、打印）或 UTF-8 CSV（可用 Excel 打开）。导出包含全部扫描目录、建议原因、影响、字节数和已选状态，不受当前筛选影响；未完成或失效的扫描会明确标记。报告会包含本机路径，请妥善保管。
- 记住偏好：时间范围和目录收藏保存在 `%LOCALAPPDATA%/AI-Cache-Cleaner/preferences.json`。不保存清理勾选，不会自动执行删除。

图标的可编辑矢量源为 `assets/app.svg`；`make_icons.py` 从代码生成多尺寸 ICO 和 PNG，Pillow 仅用于构建，最终 exe 无需安装任何依赖。

## 范围与保护

支持识别 Codex、Claude、ChatGPT、Cursor、Windsurf、Antigravity、VS Code、Trae、CodeBuddy、Cherry Studio、LM Studio 等应用的标准 AppData 目录，以及部分 Microsoft Store 安装布局。实际只显示本机存在且没有链接重定向的目录。

Microsoft Store 的目录虚拟化可能让同一份数据出现在两个路径下；工具按文件系统目录身份去重，避免重复统计。

- 可清理：白名单中的 Electron/Chromium 渲染缓存、着色器缓存、部分扩展安装包缓存，以及手动选择的日志。只删除符合天数条件的文件，保留目录结构。
- 只统计：Ollama、Hugging Face、Whisper 和 LM Studio 默认路径中的模型。
- 不清理：登录凭据、Cookies、Local Storage、聊天和 CLI 会话、工作区、项目、应用程序、已安装扩展，以及 `.codex/plugins/cache` 中可能正在使用的插件运行时。
- Cline、Roo Code、Continue 等 VS Code 插件的数据与工作区状态可能混存，不直接清理它们的 globalStorage。仅统计宿主 VS Code 的通用缓存。

这是已知路径扫描器，不是全 C 盘文件内容搜索器。不会自动发现所有品牌、其他 Windows 用户、自定义安装数据路径或自定义模型路径。不会扫描浏览器中的 AI 网站数据。

## 删除行为

文件会**直接删除，不进入回收站**，操作前会显示应用、目录数、文件数和预计空间并要求确认。此仓库交付和验证期间只扫描真实缓存，未清理真实应用数据。

扫描与删除都跳过符号链接、Windows 目录联接和其他 reparse point；批量扫描核对打开目录的最终路径及根目录归属，清理时独立重新验证白名单、路径归属、祖先目录、文件大小和修改时间。扫描后改变的文件会跳过。被占用或无权限的文件失败后继续，并在报告中记录，不强制结束任何进程。

请先关闭应用，避免缓存立即再生成或与写入竞争。Agent 模式的路径检查无法完全消除其他进程在极短时间内更换目录造成的竞争；本工具适合可信的本机环境。全盘模式新增的清理流程使用同一个 Windows 文件句柄核对最终路径、文件身份、大小、修改时间和属性后标记删除，打开期间不共享写入 / 删除权限；文件被占用或发生变化则跳过。该方式基于 [CreateFile](https://learn.microsoft.com/en-us/windows/win32/api/fileapi/nf-fileapi-createfilew) 和 [FILE_DISPOSITION_INFO](https://learn.microsoft.com/windows/win32/api/winbase/ns-winbase-file_disposition_info)。占用为文件逻辑大小之和，实际释放量可能受压缩、硬链接和文件系统分配影响。规则无法判断每个文件的业务价值，建议仍应在预览中核对文件；报告包含本机路径，应按个人数据保管。

## 开发和验证

仓库保留可编辑图标源与生成脚本；PNG、ICO 和界面图形资源由构建脚本生成，不包含本机扫描报告或偏好。

```powershell
py -3.12 -m pip install -r requirements-build.txt
py -3.12 make_icons.py
py -3.12 -m unittest -v
py -3.12 cleaner.py --scan --days 7
```

命令行仅提供只读扫描，没有自动清理参数。安全测试只操作测试临时目录。

## 扫描性能与新版界面

- Windows 目录批量读取文件大小、修改时间和 128 位文件身份，避免逐文件重复获取元数据；每个目录句柄核对最终路径是否仍在扫描根目录内，不沿重解析点走出根目录。
- 全盘分析继续按身份去重目录别名与硬链接。缓存清理建议先按年龄、属性和格式排除文件，只对可能进入预览的文件额外核对身份和硬链接数。
- Agent 缓存和各类清理建议最多使用 4 个读取线程；停止后取消排队任务。全盘分析直接开始空间统计，缓存建议按需加载，避免先后扫描造成的等待。
- 清理阶段的根目录白名单、保护规则、完整预览、文件句柄校验和不共享写入 / 删除权限均保留；本轮只优化读取和展示。
- 本机 pip 缓存同范围对照（均开启 cProfile）：旧版 37.6 秒，新版 6.9 秒；1367 个符合规则的文件、字节数、修改时间及身份摘要完全一致。此结果受缓存冷热、系统负载和目录结构影响，不等于全盘均提升相同比例。
- 界面改为顶部模式切换、白灰内容区、蓝色主操作和全宽表格。移除侧栏、宣传语、卡片说明、快捷键说明和重复操作提示；详情按需打开。图标替换为蓝色磁盘造型，不再使用盾牌或 C 字标。扫描和停止保留在每个模式的主工具栏，清理仍通过文件清单二次确认。

原生批量枚举结构参考 [FILE_ID_EXTD_DIR_INFO](https://learn.microsoft.com/windows/win32/api/winbase/ns-winbase-file_id_extd_dir_info)。不支持该枚举信息类时回退到标准目录读取，不降低删除校验。

## Windows 11 风格

圆角按钮、面板和输入框使用构建时生成的图形资源；工具按钮统一使用同一套线框图标。窗口与确认对话框使用 [DWM 圆角偏好](https://learn.microsoft.com/en-us/windows/apps/desktop/modernize/ui/apply-rounded-corners)，保留系统边框和窗口管理行为。

Agent 与全盘清理页均提供「全选推荐项」，范围为本次有效扫描中的全部推荐项，包含筛选隐藏的目录。不会自动勾选日志、模型、受保护内容或需检查的项。该按钮只改变选择；删除仍须通过文件预览确认。

默认跟随 Windows 应用主题，右上角可选择「跟随系统 / 浅色 / 深色」，选择自动保存。系统主题变化后约 1 秒内同步，切换保留扫描结果与勾选项。列表、图标、输入框和确认窗口同步适配。主题检测只读取 Windows 设置，不修改系统主题。实现参考 [Windows 应用主题设置](https://learn.microsoft.com/en-us/windows/apps/develop/settings/settings-common)与 [DWM 深色标题栏](https://learn.microsoft.com/windows/apps/desktop/modernize/apply-windows-themes)。

## 打包

开发电脑安装 Python 3.12 后运行 `powershell -ExecutionPolicy Bypass -File .\build.ps1`。脚本会在本项目的 `.build-venv` 中安装构建依赖、运行测试，再生成不带控制台的单文件 Windows x64 程序 `dist/Clearspace.exe`。最终用户只需要 exe；旧文件名会同步保留相同二进制，推荐使用新名称以刷新 Windows 的图标缓存。

运行 `dist/AI-Cache-Cleaner.exe --self-test` 可检查内置运行环境、窗口、Agent 只读扫描、模式切换及全盘分析引擎。全盘引擎自检使用自建的临时样本目录，不会自动扫描全盘；完成后清除自建样本并退出，在报告目录生成 `self-test-*.json`。自检不会删除缓存。
